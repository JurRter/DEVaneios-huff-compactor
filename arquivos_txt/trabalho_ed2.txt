Linguagem Permitida: C ou Java

Abordagem: Implementação Completa (Codificador e Decodificador)
1. Contexto e Objetivo

A compressão de dados é uma aplicação fundamental das estruturas de dados não-
lineares. O objetivo deste trabalho é aplicar os conceitos de Árvores Binárias, Filas de

Prioridade (Min-Heaps) e Tabelas Hash para implementar um software utilitário de
linha de comando capaz de compactar e descompactar arquivos de dados usando o
Algoritmo de Huffman.

Parte B: O Decodificador (Descompressão)
O processo de descompressão deve reverter o arquivo .huff :
1. O Codificador (Compressor): Aplica o algoritmo de Huffman buscando minimizar o
tamanho de um arquivo original gerando um arquivo .huff .
2. O Decodificador (Decompressor): Lê o arquivo .huff e reconstrói o arquivo
original sem perda de nenhum byte.

1. Frequência: Ler o arquivo de entrada byte a byte (8 bits) e calcular a frequência de
ocorrência de cada um dos 256 bytes possíveis.
2. Gravação do Arquivo ( .huff ): O arquivo de saída deve conter:
Cabeçalho: A tabela de frequências (ou a árvore serializada) para que o
decodificador possa reconstruir a árvore (ver mais detalhes no formato do
arquivo abaixo);
Dados: A sequência de bits correspondente aos bytes originais codificados.

3. Formato do Arquivo de Saída ( .huff )
